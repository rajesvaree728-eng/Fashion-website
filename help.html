Welcome to our Help section. If you are facing any issues while browsing or using this website, you can find quick solutions below.

How to Browse Products

  • Go to the category you want (Men, Women, Footwear, Accessories, Ethnic, Trending).
  • Products will load automatically from our JSON API.
  • Click on any product to view details (if detail page is added).

Images Not Loading?

Solution: Always open the website using Live Server.

Opening directly in Chrome (file:///C:/...) will block local JSON fetching and image assets due to browser security restrictions.

Facing Slow Loading?

  • Check your internet connection.
  • Make sure images are inside the correct project directory folder.
  • Ensure asset file names match exactly with your JSON paths.

Common Errors & Fixes

  • CORS Error — Serve the project locally using Live Server.
  • 404 Not Found — Double check image file extension casing and folder path structures.
  • JSON Error — Check for missing commas, trailing slashes, or spelling errors in your fetch path.
