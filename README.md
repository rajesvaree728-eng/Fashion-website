# 🛍️ Premium E-Commerce Storefront

A sleek, minimal, and premium e-commerce storefront designed with a warm, earthy Gen-Z aesthetic. This project focuses on high-fidelity UI design, strict semantic markup, and fluid responsiveness without relying on heavy external frameworks.

🔗 **[Live Demo](https://github.com/rajesvaree728-eng)** | 💼 **[My Portfolio](https://github.io)**

---

## ✨ Core Features

* **Interactive Fashion Showcase:** Hover over product cards to dynamically reveal rich product metadata and purchasing details.
* **Gen-Z Aesthetic:** Designed with a curated, modern, and minimal visual layout tailored for a luxury shopping experience.
* **Fully Responsive:** Fluid layouts designed with modern CSS system architectures to adapt beautifully across mobile, tablet, and desktop screens.
* **Performance First:** Lightweight execution using native browser features for optimal loading times.

---

## 🛠️ Tech Stack & Concepts Demonstrated

* **Semantic HTML5:** Built using standard accessibility and structural elements (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) to ensure clean SEO structure.
* **Modular CSS3 Layouts:** Structured using modern layout architectures like CSS Flexbox and Grid to handle intricate visual structures cleanly.
* **Vanilla JavaScript:** Utilized for handling lightweight DOM manipulations and smooth client-side interactions.

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd Fashion-website
   ```
3. Open `index.html` directly in your favorite browser, or use a tool like VS Code's **Live Server** extension.
